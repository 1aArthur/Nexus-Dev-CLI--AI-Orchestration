# Build Output Mounting Point

This directory is reserved for Flutter release artifacts generated by `flutter_nexus_dev/build_release.sh`.

## Expected Artifacts

```
build_output/
├── android/
│   └── app-release.apk
└── ios/
    └── Runner.ipa
```

## Generation

```bash
cd flutter_nexus_dev
bash build_release.sh both
```

Artifacts will be copied here after successful compilation and signing.
