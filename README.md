# Nexus-Dev-CLI--AI-Orchestration

Flutter-based AI orchestration CLI with DevSecOps, multi-agent monitoring, CI/CD pipelines, and native module generation.

## Structure

- `flutter_nexus_dev/` — Full Flutter application source (lib/, android/, ios/, pubspec.yaml, build scripts)
- `build_output/` — Artifact mounting point for generated APK and IPA files

## Build Artifacts

Build outputs are mounted under `build_output/`:

```
build_output/
├── android/
│   └── app-release.apk         # Generated by build_release.sh
└── ios/
    └── Runner.ipa              # Generated by build_release.sh
```

## Building

```bash
cd flutter_nexus_dev

# Generate code (Freezed, Riverpod)
flutter pub get
dart run build_runner build

# Build APK
flutter build apk --release

# Build IPA
flutter build ipa --export-options-plist ios/ExportOptions.plist
```

Or use the provided script:

```bash
bash build_release.sh android   # APK only
bash build_release.sh ios       # IPA only
bash build_release.sh both      # Both artifacts
```
